Drop your resume, project write-ups, current job description, and anything else
about your experience in this folder (.pdf, .docx, .md or .txt). Or set CORPUS_DIR
in .env to a Google Drive folder instead.

On the next run, these files are condensed into `profile.md` at the project root.
The profile is rebuilt automatically whenever the files change. Read it to check
what the matcher believes about you.

Everything in this folder except this README is gitignored.
